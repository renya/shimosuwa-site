# IrfanViewでInstagram投稿用写真を選別する手順

## 目的

大量の写真からInstagram投稿用の写真を選別する。

例：

```text
396枚
↓
候補20枚
↓
Instagram投稿10枚
```

---

# 前提

Web公開用写真は事前に作成済み。

設定：

```text
長辺1920px
JPEG品質85
```

---

# 候補フォルダ作成

候補写真を集めるためのフォルダを作成する。

例：

```text
C:\TEMP\instagram-candidate
```

---

# 写真閲覧

最初の写真をIrfanViewで開く。

例：

```text
img_3427.jpg
```

---

# 写真移動

キーボード操作

```text
→ 次の写真
← 前の写真
```

写真をテンポよく確認する。

---

# 候補写真をコピー

良い写真を見つけたら

```text
F8
```

を押す。

---

# 初回設定

F8画面でコピー先を設定する。

例：

```text
C:\TEMP\instagram-candidate
```

ポイント：

```text
存在しないフォルダでも自動作成される
```

---

# コピー

コピー先設定後

```text
OK
```

を押す。

候補写真が

```text
C:\TEMP\instagram-candidate
```

へコピーされる。

---

# 選別基準

Instagram用は単なるベストショットではなく、

```text
入口
↓
登山道
↓
稜線
↓
山頂
↓
展望
↓
下山
```

のようなストーリーを意識する。

---

# おすすめ運用

## 1次選考

全写真を見る。

例：

```text
396枚
```

気になった写真はF8でコピーする。

目標：

```text
15〜20枚
```

---

## 2次選考

候補フォルダのみを見る。

例：

```text
C:\TEMP\instagram-candidate
```

ここから最終選抜を行う。

目標：

```text
10枚
```

---

# 鷲ヶ峰実績

撮影枚数：

```text
396枚
```

選抜：

```text
10枚
```

構成：

```text
登山口
↓
登山道
↓
稜線
↓
山頂標識
↓
展望
↓
下山
```

Instagramカルーセル投稿用として使用。

---

# ポイント

Instagramは写真単体の美しさだけでなく、

```text
体験の流れ
```

が伝わる構成を優先する。

そのため、

```text
似た絶景写真を並べる
```

よりも、

```text
歩いた流れが分かる写真を選ぶ
```

方が効果的である。
