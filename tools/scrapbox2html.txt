# 入力欄への記入内容
#
# これは shimosuwa.info 用の静的HTML変換です。一般的なWeb記事風に整理せず、scrapbox2html.txt のルールを優先してください。
# scrapbox2html.txt の指示に従って、scrapbox.txt を HTML 化してください。
# CSSは添付の style.css のみを前提にしてください。
# 出力は完成した index.html 全文のみでお願いします。

以下のHTML構造をテンプレートとして扱ってください。
ヘッダーとフッターはそのまま使って下さい。
class名・タグ構造・レイアウト方針を維持してください。

重要:
- CSSは添付の style.css のみを前提にすること
- 新しい class 名・独自CSS・inline style を追加しないこと
- Grid レイアウトを増やさないこと
- HTMLは既存CSSで表示可能な構造のみ使用すること

- title・meta description・h1 はページ内容に合わせて変更すること
- ヘッダーとフッターのHTML構造は維持すること

- scrapbox2html.txt は変換ルールとして扱う

- scrapbox.txt の本文順・内容はできるだけ変えないこと
- 内容を整理・要約しないこと
- h2/h3を勝手に追加しないこと
- 本文中に不要な div を増やさないこと
- 不要な空白行を増やさないこと
- class の入れ子を必要以上に深くしないこと

- X/Twitter引用は scrapbox2html.txt の x-quote 形式を使うこと
- X/Twitter引用内の連続画像は必ず gallery div の中にまとめること
- X/Twitter引用中の画像を ul/li にしないこと
- X/Twitter引用内で > 行が連続している場合は、同じ x-quote 内の本文として扱うこと
- X/Twitter引用ブロックは途中で分割しないこと
- gallery div の外に X/Twitter引用画像を出さないこと
- X/Twitter引用内の本文は p タグで囲まないこと
- X/Twitter引用内では、本文テキストと gallery div のみで構成すること
- X/Twitter引用内で改行が必要な場合は br を使うこと

- テーブルは scrapbox2html.txt の table-wrap 形式を使うこと
- table: で始まる行は table の開始として扱うこと
- table: の後ろの文字列は table のタイトルとして扱うこと
- table: の次の行はヘッダー行(th)として扱うこと
- その後のタブ区切り行を table のデータ行(td)として扱うこと
- table の列数はデータ行の最大列数に合わせること
- table の列数が不足する行は空セル(td)を補完すること
- table のヘッダー行が「初日 中日 最終日」のように1列目の見出しを省略している場合、1列目の空見出し th を補完すること
- ヘッダー行の列数が不足する場合は、先頭または末尾に空の th を補完して列位置を合わせること
- table は空白やタブで見た目だけを整えず、必ず <table><tr><th><td> で構成すること
- table 内のセル結合(colspan/rowspan)は使わないこと
- table は table-wrap div の中に配置すること

- > で始まる通常引用行は、1行ごとに空行を入れず、連続した行として詰めて表示すること
- > で始まる通常引用行を p タグで分割して余白を増やさないこと
- > で始まる行は、原則として通常引用 blockquote として扱うこと
- > 行を X/Twitter引用と判定しないこと
- X/Twitter引用にするのは、Twitter/XのURL行と、その直後に続く引用本文・画像が一体になっている場合のみとすること
- > 行がX/Twitter投稿本文として使われている場合でも、HTML上では p タグを使わず、x-quote 内の本文テキストとして扱うこと
- Twitter/X URLを含まない > 行は必ず通常引用 blockquote として扱うこと
- > はScrapbox上の引用記法であり、X/Twitter引用の印ではない

- 連続する画像は gallery div の中にまとめること
- gallery は通常画像にも使用してよい
- gallery の中には img タグのみを配置すること
- gallery 内で ul/li を使わないこと
- gallery をカードUI化しないこと
- gallery はシンプルな画像グループとして扱うこと
- 画像サイズ指定をHTMLに書かないこと

- 出力は完成した index.html 全文のみとする
- ただし、コピーしやすいように index.html 全文を ```html のコードブロックで囲むこと
- コードブロック外には説明文を書かないこと
